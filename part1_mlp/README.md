# Часть 1. Многослойный перцептрон (ООП)

Полносвязная нейронная сеть, написанная с нуля на NumPy, и консольное
меню для её создания, обучения и использования.

## Структура

```
part1_mlp/app/
├── __init__.py
├── main.py           — консольное меню (класс Application)
├── models.py         — Activation, Sigmoid, ReLU, DenseLayer, NeuralNetwork
├── manager.py        — DatasetManager: загрузка CSV, train/test, нормализация
├── exceptions.py     — собственные классы исключений
├── utils.py          — разбор ввода пользователя, график ошибки
└── generate_data.py  — генератор тестового набора данных
```

## Возможности

- инициализация весов случайными числами (нормальное распределение);
- прямой проход с функциями активации sigmoid и ReLU, смена активации;
- обратное распространение ошибки и мини-батчевый градиентный спуск;
- история ошибки (MSE) по эпохам и её график (matplotlib);
- сохранение и загрузка весов в JSON;
- загрузка CSV, нормализация (standard / minmax), разбиение train/test;
- собственные исключения: `InvalidLayerSizeError`, `MismatchedDataError`,
  `DatasetFileError`, `WeightsFileError`, `InvalidInputError` и др.

## Запуск

Все команды выполняются из корня репозитория с активированным окружением.

```bash
# 1. Сгенерировать тестовые данные (data/input/students.csv)
python -m part1_mlp.app.generate_data

# 2. Запустить меню
python -m part1_mlp.app.main
```

Параметры генератора: `--rows 300 --seed 42 --output путь.csv`.

## Пример сеанса

1. Пункт 1: слои `4 8 1`, активация `relu`.
2. Пункт 2: путь по умолчанию, доля теста 0.2, нормализация standard.
3. Пункт 3: скорость 0.5, 200 эпох, батч 16. Точность на тесте около 92%.
4. Пункт 4: ввести `5.5 80 7 4` — получим класс 1 (студент сдаст).

## Настройки (переменные окружения / файл .env)

| Переменная     | По умолчанию   | Назначение                      |
|----------------|----------------|---------------------------------|
| `DATA_PATH`    | `data/input`   | папка с входными данными        |
| `OUTPUT_DIR`   | `data/output`  | папка для весов и графиков      |
| `DATASET_FILE` | `students.csv` | имя CSV-файла по умолчанию      |
| `RANDOM_SEED`  | `42`           | зерно генератора случайных чисел |

## Формат CSV

Первая строка — заголовки, последний столбец — целевая переменная
(0/1 для одного выхода или номер класса для нескольких выходов),
остальные столбцы — числовые признаки.
